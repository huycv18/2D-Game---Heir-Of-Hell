# 🔄 ROLLBACK: Quay về PlayerController cũ

## 🎯 Mục đích
Tạm thời tắt hệ thống Possession mới, quay về PlayerController cũ để game hoạt động bình thường.

**Không lo:** Possession System vẫn còn đó, bạn có thể bật lại bất cứ lúc nào!

---

## ✅ CÁCH TẮT POSSESSION SYSTEM (30 GIÂY)

### Bước 1: Disable PlayerBrain
1. **Hierarchy** → Tìm GameObject **PlayerBrain**
2. **Uncheck** checkbox bên cạnh tên (ở đầu Inspector)
3. → PlayerBrain sẽ bị disable (màu xám)
